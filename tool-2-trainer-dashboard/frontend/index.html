Lebensläufe der Teilnehmer importieren

📋 So funktioniert der Import

  1. Bitten Sie jeden Teilnehmer, in der CV-App auf „Daten exportieren (für Trainer)" zu klicken — das erstellt eine .json-Datei.
  2. Sammeln Sie die Dateien auf einem USB-Stick oder Ordner.
  3. Wählen Sie hier eine einzelne .json-Datei oder eine .zip-Datei mit mehreren JSONs aus.
  4. Geben Sie einen Kursgruppenname ein (z.B. Kurs-2026-Q2) — dieser hilft später beim Filtern.
